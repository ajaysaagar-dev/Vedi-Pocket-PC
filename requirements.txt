# `uvicorn[standard]` (or a manual `pip install websockets wsproto`),
# FastAPI's `@app.websocket("/ws")` route silently fails every
# upgrade request and the backend logs:
#   "WARNING: No supported WebSocket library detected."
# Pinning `[standard]` here forces the right extras on every install.
